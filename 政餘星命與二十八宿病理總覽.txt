# 政餘二十八宿與人體對應：推算方式與整合列表

## 一、需要先說明的範圍與依據

政餘星命學（果老星宗一系，以七政、四餘、二十八宿為骨幹）中，二十八宿與人體的對應並非只有一套固定說法。主要來源有二：

1. **《二十八宿分野》與《宿曜經》系統**：以宿配臟腑、配身體部位，屬於印度宿曜（二十八宿為二十七宿制加一）傳入後與中土分野、臟象合流的產物。
2. **後世政餘家（明清以降）實務用法**：把二十八宿再對應十二地支（每支配二或三宿），並以「宿—地支配對」落到身體部位與經脈。

所以下列內容是**這些傳統系統中較通行的一種整理**，並非全體政餘家一致同意的唯一版本；不同師承在「某宿究竟配某部位」上會有出入。凡我有疑慮處會標示。

我按你的要求做三件事：（1）講對應原理；（2）講凶星入宿的推算方法；（3）給你 12 地支 ↔ 28 宿 ↔ 人體部位的表，並整合成 HTML。

---

## 二、二十八宿對人體的基本原理

政餘的思路不是「一宿對一個器官」這麼簡單，而是三層疊加：

- **宿 → 地支（宮）**：二十八宿分布於十二宮（地支），每宮二或三宿。宿落哪一宮，就帶上該宮的五行與身體部位屬性。
- **宿 → 四象（四方七宿）**：東方蒼龍（角亢氐房心尾箕）、北方玄武（斗牛女虛危室壁）、西方白虎（奎婁胃昴畢觜參）、南方朱雀（井鬼柳星張翼軫）。四象各主一身之「上/下、陰/陽、左/右」大區塊。
- **宿 → 臟腑**：多數宿有傳統的臟象配屬（如角宿主肝、心宿主心、胃宿主脾胃、虛宿主腎等），這部分各家差異最大。

凶星（火、土、羅、計、孛，以及失陷之金水日月）入宿時，是「**該宿的身體部位 + 該宿所落宮位的部位**」兩者疊加取象，再看凶星本身的性質（火主炎症熱症、土主積聚寒濕、羅計主手術刀傷與突發、孛主水濕腫脹與血疾）決定病性。

---

## 三、凶星入宿推算健康與病痛位置的步驟

依政餘實務，可整理為五步：

**第一步：定位**

看命盤中凶星所在之宿（黃道二十八宿位置），記下：宿名、所落宮（地支）、所落宮的度數、星曜本身的廟旺落陷。

**第二步：取象兩源**

- 從「宿」取身體部位（該宿傳統臟象）；
- 從「宮（地支）」取身體部位與經脈（如子主腎、亥主頭、辰主胃脘等）。
兩者若一致，病位明確；若不一致，以「宿為體、宮為用」，即宿定發病之臟器，宮定外顯部位或經絡路徑。

**第三步：定病性（由凶星性質）**

| 凶星 | 病性取象 |
|---|---|
| 火星（及計都偏火時） | 炎症、發熱、外傷、出血、急性 |
| 土星 | 積聚、寒濕、慢性、骨節、遲滯 |
| 羅睺 | 突發、腫瘤、異物、手術、中毒 |
| 計都 | 刀傷、斷裂、舊疾復發、隱疾 |
| 孛星（月孛） | 水濕、腫脹、血疾、婦科、泌尿 |
| 失陷之日/月 | 元氣虛、眼疾、精神耗弱 |

**第四步：看宿的吉凶「體性」**

二十八宿本身有吉宿、凶宿之分（如角、房、心、虛、畢、觜、參、鬼、軫等常列為多凶或多災之宿）。凶星落凶宿，其象加重；凶星落吉宿，則病較輕、或病在表。

**第五步：合參宮主、宿度主與流年**

- 該宿所落宮的**宮主星**若也受傷，病位由「可能」升為「確指」。
- **宿度主**（如角宿度主木、亢宿度主金等，各家不同）受傷亦同論。
- **流年宿**：行限或流年凶星過本命之宿或其對宮宿，為發病之年。

# 十二地支 → 人體部位對照

單純保留「地支 ↔ 人體部位」這層關係，不涉宿、不涉星曜。地支配身體有兩個常見取徑：一是**臟腑（十二臟象）**、一是**身形（由頭至足的體位分布）**。兩者常並列使用，下表兩者都給，方便你依需求取用。

## 十二地支人體對應表

| 地支 | 對應臟腑 | 對應身形／部位 |
|---|---|---|
| 子 | 腎、膀胱 | 下焦、耳、生殖器、足底 |
| 丑 | 脾、胃 | 腹部、腰、足脛 |
| 寅 | 膽 | 坐骨、大腿、下肢關節 |
| 卯 | 肝 | 脅肋、手指、目 |
| 辰 | 胃、脾 | 胸膈、肩、皮膚 |
| 巳 | 心、小腸 | 面、咽喉、上臂 |
| 午 | 心 | 背、頭頂、血脈、目 |
| 未 | 脾、小腸 | 腹中、脊、頭面 |
| 申 | 肺、大腸 | 肩背、骨節、鼻 |
| 酉 | 肺、大腸 | 口、齒、氣管、腰 |
| 戌 | 胃、心包 | 腹壁、足膝、腿 |
| 亥 | 腎、三焦 | 頭、腦、足、精室 |

一點差異提醒：地支的「身形取象」有多種排法。常見的是**由下而上**（子為下焦、亥為頭頂，倒序配身形）；也有把**午定為頭、子定為足**的正序排法。上表身形欄採「子在下、亥在頭」這一較通行的政餘／子平共用排法。若你用正序（午為頭），把身形欄整欄反轉即可。
